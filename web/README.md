# CARD Catalog — React app (PoC)

A GDC-style React port of the Streamlit pages. Read-only: all data is sourced
from the latest TSVs produced by the Python pipeline.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- React Router (URL-synced filters → shareable links)
- TanStack Table (sortable grids)
- papaparse (in-browser TSV parsing)
- react-flow (knowledge graph views)
- FastAPI backend stub for LLM-analysis calls (Anthropic-proxy only)

## Quick start

Requires Node 18+ and Python 3.10+.

```bash
cd web
npm install
npm run sync-data        # copy latest pipeline TSVs into public/data/
npm run dev              # http://localhost:5173

# Optional, only if you want to wire up LLM analysis later
cd backend
pip install -r requirements.txt
ANTHROPIC_API_KEY=sk-ant-... uvicorn main:app --reload --port 8000
```

Re-run `npm run sync-data` whenever the pipeline writes new outputs.

```
      Header.tsx                  — top nav + global search
      FilterRail.tsx              — left sidebar wrapping N Facet widgets

      DataTable.tsx               — TanStack table wrapper
      PageShell.tsx               — header + rail + main slot
      Chips.tsx                   — semicolon-split chip rendering
      KnowledgeGraph.tsx          — react-flow shared-attribute graph (stub)
    pages/
      PublicationsPage.tsx
      ResourcesPage.tsx

      CellularModelsPage.tsx
  scripts/

    requirements.txt
  public/data/                    — gitignored, generated by sync-data
```

## What's done

- All five table-based pages with facets, search, sort, URL state.
- Cross-entity nav: Publications row chips → `/datasets?pmc=…` with three sub-tabs.
- react-flow knowledge graph (shared-disease edges) on Resources and Publications.
- FastAPI scaffold so a future "Analyze this subset" button has somewhere to call.

## What's stubbed / deferred

- **Knowledge graph styling**: deterministic circle layout, capped at 60 nodes.
  Switch to a force-directed layout (`d3-force` driving `reactflow`) and add
  node click → entity detail when polish time arrives.
- **LLM analysis UI**: backend endpoint exists but no React component calls it
  yet. The button + side panel should land alongside any work that pre-computes
  context summaries in the pipeline.
- **Detail pages**: clicking a row currently opens the external URL only.
  Adding `/publications/:pmid`, `/resources/:abbrev` etc. is the natural next
  step and reuses `PageShell` minus the rail.
- **Charts / overview dashboards**: not yet ported (Streamlit pages have a few
  via plotly/pyvis). Add a `<DashboardStrip />` component using `nivo` or
  `visx` when needed.

## Performance notes

- `scilite_annotations.tsv` is ~43 MB. Loads in ~3 s on a modern laptop and
  filtering is responsive after that. If it grows past ~100 MB switch to
  partitioned files (`/data/scilite/PMC11401759.json`) or DuckDB-WASM with a
  parquet build artifact.
- Every facet panel iterates every row each render. Memoised via `useMemo` so
  it only re-runs when the source list changes. Fine up to a few hundred
  thousand rows.
